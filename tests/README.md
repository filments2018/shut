# SHUT E2E

追加依存なしで、Chrome DevTools Protocolを使ってiPhone相当の撮影フローを確認する。

1. ローカルサーバーを起動する。
2. Chromeをリモートデバッグポート付きで起動する。
3. テストを実行する。

```sh
SHUT_CDP_PORT=9335 node tests/e2e-additions.mjs http://127.0.0.1:8000
```

確認対象:

- 音声あり／なし設定の保存
- 端末チェックの正常・カメラ拒否・正常復帰
- 3分割構図ガイドの表示と設定保存
- 撮影開始前のフロント／リアカメラ切替とRecorder再接続
- Screen Wake Lockの取得と解放
- 移動待機中の録画停止表示
- シーンA確認フレームと撮り直し
- シーンBの保存前確認と録画一時停止
- 完成画面のシーンA/B確認フレーム
- 診断レポートのコピー
- 動画Blobとプレビュー生成
- バックグラウンド移動時の録画一時停止と明示的な再開
- 中断したシーンの残り撮影時間からの再開
- 連続撮影の準備中にバックグラウンドへ移動した場合の自動再開解除
- コンソールエラー0件
